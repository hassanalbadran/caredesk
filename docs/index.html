CareDesk

Free and open-source clinic booking, session timers and patient reminders for Windows. Works offline. No activation code, no subscription.

Open the releases page Beta release (v0.1.0-beta.1)

Download the Windows installer (.exe) from the releases page. The app updates itself from inside once a newer release is published.

What it does

  • A month calendar as the home screen, with one button per session type and the number of patients on each day.
  • Per-device hour grids with numbered patient circles, session timers that survive restarts, drag-and-drop rescheduling and right-click menus.
  • Smart scheduling: pick a patient class or drag the first sessions onto the calendar and the rest are distributed automatically. Full days are flagged red, nearly full yellow.
  • Patient profiles with grouped sessions, tags, priorities (VIP, late-comers, drop-outs) and maintenance reminders.
  • WhatsApp reminders, printable receipts with a visual receipt designer, barcodes and rating links.
  • Live statistics for the manager and granular permissions for secretaries and admins.
  • Import patients from CSV, Excel, JSON, vCard, SQL or SQLite, and export them back.
  • Built-in system check and safe auto-repair (Ctrl + Shift + D) that saves a safety copy first and never deletes patients or sessions.
  • Optional phone link on the same Wi-Fi to follow today's sessions from a phone.
  • Arabic and English interface.

Privacy

Patient data stays on your computer. Only an error code and a short description (never patient names) may be sent to the support dashboard to help fix problems.

Build from source

npm install → npm start to run, npm test for the tests, npm run dist to build the Windows installer.

Built with Electron and the built-in node:sqlite. Released under the MIT license.
